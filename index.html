The core idea

Bitcoin as the only foundation.

BITRUBIN is designed to complement Bitcoin, not replace it with a second blockchain. BRBN and Pearls are intended to be derived from defined Bitcoin transactions and independently verifiable rules.

01 / BITCOIN

One blockchain

Bitcoin remains the only blockchain and the only consensus foundation. No separate BITRUBIN chain, mining, or validator consensus.

02 / VERIFICATION

Your own Bitcoin node

Participants are intended to verify Bitcoin data with their own Bitcoin Core full node. A second independently operated node provides an additional cross-check.

03 / RULES

BITRUBIN CORE

A deterministic verification and interpretation layer is intended to evaluate Bitcoin history and calculate protocol state from it.

Technical approach

No second blockchain.

Bitcoin determines which blocks and transactions belong to the valid Bitcoin chain. BITRUBIN CORE is intended to verify this data independently and apply the defined BRBN and Pearls rules. It does not replace Bitcoin consensus.

Proposed token rules

BRBN & Pearls

The BITRUBIN symbol is a complete ruby-red R with two horizontal bars. The BITPEARL symbol is a complete pearl-white P with two horizontal bars. Both use matching gold edging.

These figures describe the current project proposal. They do not mean that tokens have already been issued or are available.

2,100,000 BRBNPublic target supply
700,000 BPRLPublic target supply
2,205,000 BRBNPlanned maximum including founder and developer allocations
735,000 BPRLPlanned maximum including founder and developer allocations

BRBN and BPRL use 38 decimal places. 1 BTC = 1 BRBN and 1 satoshi = 1 Rubini are nominal unit definitions only. One Rubini equals 10^30 smallest BRBN units. BPRL requires valid BRBN issuance; the public BRBN target is divided into four epochs of 525,000 BRBN and the BPRL allocation rate halves at each successive epoch. Exact integer-rate and rounding rules must be finalized before activation. All calculations use deterministic integer arithmetic.

The unit definitions do not promise market value, backing, redemption, or convertibility.

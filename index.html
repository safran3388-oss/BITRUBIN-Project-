THE CENTRAL MECHANISM

Bitcoin burn through positive-value OP_RETURN

The defining idea of BITRUBIN is that every qualifying positive-value OP_RETURN output in a Bitcoin transaction counts. No special BITRUBIN marker is required. The output is provably unspendable; the BTC assigned to it is therefore intended to be treated as burned under the protocol rules.

How the proposed mechanism works

01 · CREATE

A user broadcasts a Bitcoin transaction containing an OP_RETURN output with a positive BTC value.

02 · VERIFY

BITRUBIN CORE reads the confirmed Bitcoin data through Bitcoin Core and checks the qualifying output.

03 · ACCOUNT

The protocol applies its deterministic rules to calculate the corresponding BRBN and Rubini issuance.

04 · PEARLS

BPRL is calculated proportionally to valid BRBN issuance, according to the fixed project rules.

Technical status: This is a proposed mechanism, not a production-ready implementation. Positive-value OP_RETURN outputs may face Bitcoin standardness and relay-policy restrictions. Their acceptance, mining, detection, ownership attribution and accounting must be tested and independently reviewed before activation.

The core idea

Bitcoin as the only foundation.

BITRUBIN is designed to complement Bitcoin, not replace it with a second blockchain. BRBN and Pearls are intended to be derived from defined Bitcoin transactions and independently verifiable rules.

01 / BITCOIN

One blockchain

Bitcoin remains the only blockchain and the only consensus foundation. No separate BITRUBIN chain, mining, or validator consensus.

02 / VERIFICATION

Your own Bitcoin node

Participants are intended to verify Bitcoin data with their own Bitcoin Core full node. A second independently operated node provides an additional cross-check.

03 / RULES

BITRUBIN CORE

A deterministic verification and interpretation layer is intended to evaluate Bitcoin history and calculate protocol state from it.

Technical approach

No second blockchain.

Bitcoin determines which blocks and transactions belong to the valid Bitcoin chain. BITRUBIN CORE is intended to verify this data independently and apply the defined BRBN and Pearls rules. It does not replace Bitcoin consensus.

Proposed token rules

BRBN & Pearls

The BITRUBIN symbol is a complete ruby-red R with two horizontal bars. The BITPEARL symbol is a complete pearl-white P with two horizontal bars. Both use matching gold edging.

These figures describe the current project proposal. They do not mean that tokens have already been issued or are available.

2,100,000 BRBNPublic target supply
700,000 BPRLPublic target supply
2,205,000 BRBNPlanned maximum including founder and developer allocations
735,000 BPRLPlanned maximum including founder and developer allocations

BRBN and BPRL use 38 decimal places. 1 BTC = 1 BRBN and 1 satoshi = 1 Rubini are nominal unit definitions only. BPRL is issued proportionally to valid BRBN issuance: the public targets are 2,100,000 BRBN and 700,000 BPRL. There is no halving and no epoch schedule. Exact integer, rounding and cap rules must be finalized before activation. All calculations use deterministic integer arithmetic.

The unit definitions do not promise market value, backing, redemption, or convertibility.
